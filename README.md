# 幼儿识字宝 - 后台管理系统 (kid-char-learn-admin)

幼儿识字宝字库教研、多媒体资源配置与用户工单中台管理系统。

## 技术栈

* **核心框架**：React 19 + TypeScript + Vite
* **UI 样式**：Tailwind CSS v4 + Lucide React 图标库
* **云开发直连**：`@cloudbase/js-sdk` 直连微信云开发数据库与云函数

## 核心功能

1. **管理员独立账号密码鉴权**：
   - 安全的管理员登录态，支持记住账号、显隐密码切换与回车快捷登录；
   - 顶部提供管理员密码修改（修改后实时同步至云数据库 `c_admin_users`）。
2. **字库与汉字管理**：
   - 4 大分级阶段（启蒙、初级、中级、高级）字库总览与发布管理；
   - **汉字精确检索**：输入单个汉字按回车精确匹配；
   - **音频上传与规范重命名**：自动重命名为纯 ASCII 规范（单字 `chars/audios/c_{hex}_{pinyin}.mp3`，组词 `words/audios/w_{hex1}_{hex2}_{pinyin}.mp3`，例句 `sentences/audios/c_{hex}_sen.mp3`）并同名覆盖；
   - **纯音频文件播放**：直接加载真实音频文件试听，杜绝浏览器合成发音。
3. **用户工单与客服系统**：
   - 支持按状态（待处理、处理中、已回复、已解决）与分类（汉字纠错、功能异常、体验建议、其它疑问）多维过滤；
   - 自动换取云端截图的临时签名 URL，支持大图灯箱预览；
   - 一键复制联系方式与 OpenID；
   - 四大幼教专属快捷短语分类模板库，答复后实时闭环同步至小程序端；
   - 支持工单删除与快速归档。

## 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器 (默认端口 3001)
pnpm dev

# 构建生产产物
pnpm build
```
